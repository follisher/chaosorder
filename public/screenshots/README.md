# App 功能截图

已接入 36 张用户提供的实机截图（已去除一张紫微夜间重复截图），完整对应关系见 manifest.json。

- 四柱八字：5 张日间 + 5 张夜间。
- 紫微斗数：3 张日间 + 3 张夜间。
- 奇门遁甲：4 张日间 + 3 张夜间。
- 六壬与六爻：3 张日间 + 4 张夜间，包括大六壬、小六壬及六爻。
- 七政四余：1 张日间 + 1 张夜间。
- 古籍阅读：2 张日间 + 2 张夜间，展示分类书架与摘录笔记。

在 `.vitepress/theme/modules.ts` 中维护 slides。空缺的 day/night 会在该模式的幻灯列表中自动跳过，配对页面切换模式时保留当前内容。全部缺图时显示待补充提示。

图片使用无损 WebP，保持原始像素与内容，页面按 1284:2778 比例展示，不拉伸、不裁剪，不使用滤镜模拟另一种模式。

36 张截图从 31,241,385 字节压缩为 9,520,222 字节，减少 69.5%。转换后已逐像素验证一致。原始 PNG 可从 Git 历史恢复。

后续截图可使用 `python scripts/compress-screenshots.py 原图目录 public/screenshots` 转换（需要 Pillow），再更新 modules.ts 与 manifest.json 中的路径。
